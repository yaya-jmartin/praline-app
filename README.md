# Praliné

A D&D-flavoured, hand-drawn recipe app for Android: tier-list cookbook, quests with step timers, chef character sheets, party missions, and a shared cookbook between two phones on the home Wi-Fi.

Start with `COMMAND_FILE_CLAUDE.md` (rules, stack, architecture) and `lightweight_explanation.md` (plain-language guide to every dependency). The signing key stays out of this repository.
